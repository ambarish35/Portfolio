# Ambarish Sarkar — Portfolio

One-page developer portfolio built with Vite, React and Tailwind CSS v4. Design inspired by [Brittany Chiang](https://brittanychiang.com).

- Edit all text in `src/data.js`.
- `npm run dev` — local dev server
- `npm run build` — production build to `dist/` (Vercel picks this up automatically)
